# 3D Chess Game 

I am making a chess game in Unity 6. I wanted to try building a game and learn how multiplayer works.

Players can create a room. Invite a friend using a room code or join someone else’s room. I have also added piece capturing draw offers and resignation.

### Built with

- Unity 6 and C#

- Netcode for GameObjects

- Unity Multiplayer Services and Relay

### Assets

The 3D models of the pieces (assets) used in this project were downloaded from sources rather than created by me.

### Current Status

The gameplay and multiplayer features are implemented. I’m still working on making room creation and joining work reliably in the published WebGL version, on itch.io.

This project has been a way to learn Unity and figure things out while building something of my own.
